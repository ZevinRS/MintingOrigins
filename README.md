# Minting Origins
This is the code that was used on the minting.minehut.gg Minecraft server then updated for its successor, the 0ModsOrigins Minecraft server.

# Usage
- Install [Skript](https://github.com/skriptlang/skript), [Skbee](https://modrinth.com/plugin/skbee), and [PoaSK](https://www.spigotmc.org/resources/poask-skript-addon.104512/) on your Minecraft server.
- Place all the files from this repo (excluding the README) into the /plugins/Skript/scripts/ folder of your server.
- Run /sk reload all in game.
- Rejoin the game.
- You should be greeted with a GUI asking you to choose your origin.
